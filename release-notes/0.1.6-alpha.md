Portierung auf **Minecraft 26.3** (Testversion, nur für den 26.3-Zweig).

**Zielversion:** Minecraft 26.3, Fabric Loader ≥0.19.5, Java 25.
**Benötigt:** [Fabric API](https://modrinth.com/mod/fabric-api) 0.163.0+26.3.
**Optional:** Mod Menu 21.0.0.

## Neu
- Der Mod läuft auf Minecraft 26.3. Alle Funktionen der 0.1.5-alpha sind übernommen: Wirtschafts-Werkzeuge, HUD-Editor, Erkennungen, Namensschilder mit Effekten, Streamer-Werkzeuge.
