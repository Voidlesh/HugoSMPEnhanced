Behebt einen **Absturz auf Minecraft 26.3** (seit 0.1.10). Das Spiel stürzte ab, sobald ein anderer Spieler im Bild war, weil die Anzeige über dem Kopf (Abzeichen) beim Start nicht eingehängt werden konnte.

## Behoben
- 26.3: Absturz „Mixin transformation of AvatarRenderer failed" (`OverheadTagMixin`, falsche Methodenangabe).
- Neu im Test: Alle Mixins werden jetzt beim Testlauf auf einmal geprüft, damit so ein Fehler nicht erst im Spiel auffällt.

## Hinweis
- Es bleibt bei **einer Jar** für 1.21.11 und 26.3: `hugosmpenhanced-0.1.12-alpha.jar`.
- Die alte Jar aus `mods` löschen. Ist die automatische Installation im Updater an, tauscht er sie selbst aus.
